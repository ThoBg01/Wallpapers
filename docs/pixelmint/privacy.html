Privacy

Core principle: PixelMint's image-processing tools run locally in your browser. Images selected for resizing, compression or palette extraction are not intentionally uploaded to a PixelMint application server.

Local processing

Image resizing, compression, palette extraction, aspect-ratio calculations, filename cleaning, keyword formatting and size estimation are performed with browser-side code.

Hosting

The site is served as static files through GitHub Pages. The hosting provider may process ordinary technical request data according to its own policies.

Advertising

The site may load Google AdSense. Google and its partners may use cookies, local storage or similar technologies to provide, measure and personalize advertising where permitted. Ad availability depends on account and site approval.

No account system

PixelMint does not require a user account and does not operate its own login database.

Changes

This page may be updated when site functionality changes. Last updated: September 18, 2026.
